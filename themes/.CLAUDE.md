# Themes — Context for AI

## Theme JSON Schema
All themes live in themes/ as .json files.
Full schema defined in internal/config/types.go.

## Required Fields
- meta.name (string)
- meta.version (string)
- colors.primary, secondary, background, foreground, accent, error, success, warning, muted (hex)
- prompt.symbol, prompt.style (single|multiline), prompt.format
- loader.frames ([]string), loader.interval_ms (int > 0)
- progress_bar.filled, progress_bar.empty, progress_bar.width (int > 0)
- cursor.style (block|bar|underline)

## Color Keys
Always use these exact keys when referencing colors:
primary, secondary, background, foreground, accent, error, success, warning, muted

## Optional Fields
- graphics.gradient.enabled, from, to, direction
- graphics.divider.style (line|wave|dots|zigzag|stars|double)
- graphics.effects.banner (glitch|rainbow|neon|typewriter|none)
- wallpaper.enabled, path, opacity (0.0-1.0), stretch, alignment
- assets.spinner, assets.banner, assets.divider, assets.icons (asset names)

## Built-in Themes
default, cyberpunk, minimal, retro, synthwave (fetched from registry)

## Validation
Run: cmdx theme validate ./themes/your-theme.json
All hex colors must match: ^#([A-Fa-f0-9]{6}|[A-Fa-f0-9]{3})$
