# Config — Context for AI

## Purpose
Loads, parses and validates theme JSON files.

## Key Files
- types.go — all Theme structs (Theme, Colors, Prompt, Loader, etc.)
- loader.go — LoadTheme(), LoadThemeFromBytes(), ListThemes()
- validator.go — ValidateTheme() and per-section validators

## Theme Struct Fields
Theme, Meta, Colors, Prompt, Loader, ProgressBar, Cursor,
BorderChars, Borders, Banner, Graphics, GradientConfig,
DividerConfig, EffectsConfig, IconsConfig, Wallpaper,
IconSet, ThemeAssets

## Validation Rules
- meta.name and meta.version are required
- All 9 color fields required, must match ^#([A-Fa-f0-9]{6}|[A-Fa-f0-9]{3})$
- prompt.style must be "single" or "multiline"
- loader.frames must be non-empty, interval_ms > 0
- progress_bar.width > 0
- cursor.style must be "block", "bar", or "underline"

## IMPORTANT
Never add new Theme fields without updating:
1. types.go (struct definition)
2. validator.go (validation rules)
3. internal/editor/model.go (buildFields for TUI editor)
4. themes/*.json built-in themes
