# TUI Theme Editor — Context for AI

## Purpose
Interactive terminal UI for editing themes live with real-time preview.
Built with Bubble Tea (Model-View-Update pattern).

## Architecture
- Model — holds theme, fields, cursor, editing state
- Update — handles key messages (↑↓ navigate, Enter edit, S save, Q quit)
- View — renders two-panel layout (fields left, preview right)

## Key Files
- internal/editor/model.go — full editor model
- internal/editor/marshal.go — theme → JSON serialization

## Field Keys
All editable fields use dot-notation keys:
meta.name, meta.author, colors.primary, prompt.symbol, etc.
applyField() maps these back to Theme struct fields.
