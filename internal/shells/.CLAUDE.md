# Shell Injection — Context for AI

## Purpose
This package handles writing theme code into shell config files so themes
persist across terminal restarts.

## Shell Interface
Every shell MUST implement internal/shells/shell.go:
- Name() string
- Detect() bool
- ProfilePath() (string, error)
- Inject(t *config.Theme) error
- Remove() error
- IsInjected() (bool, error)

## Critical Rules
- ALWAYS wrap injected code with InjectStart/InjectEnd markers
- InjectStart = "# >>> cmdx theme start >>>"
- InjectEnd = "# <<< cmdx theme end <<<"
- ALWAYS backup profile before writing
- ALWAYS use removeInjection() before re-injecting to prevent duplicates
- NEVER hardcode profile paths — use os.UserHomeDir()

## Per Shell Notes
### PowerShell
- Profile: $HOME/Documents/PowerShell/Microsoft.PowerShell_profile.ps1
- Uses Write-Host for colored output
- Uses $env:USERNAME for username
- Git branch via: git branch --show-current

### Zsh
- Profile: ~/.zshrc
- Uses ANSI escape codes \033[38;2;R;G;Bm for truecolor
- Uses hexToRgbAnsi() for color conversion
- Git branch via: git branch 2>/dev/null | grep '^*'

### Bash
- Profile: ~/.bashrc or ~/.bash_profile
- Same ANSI approach as zsh
- Check ~/.bashrc exists before ~/.bash_profile
