# Asset Engine — Context for AI

## Purpose
Converts user-uploaded PNG files into terminal-renderable output using chafa.

## Asset Types
- spinner — animated PNG frames (frame1.png, frame2.png, etc.)
- icon — small inline graphics per icon key
- banner — wide header graphic on startup
- divider — horizontal separator line
- floater — corner decorative graphic (TODO)
- mascot — reactive character with states (TODO)
- status-bar — bottom info bar (TODO)

## Render Modes (best to worst quality)
1. sixel — actual pixels, Windows Terminal + iTerm2 + Kitty
2. braille — ⣾⣽⣻ smooth, any terminal
3. blocks — █▓▒░ bold, any terminal
4. ascii — characters only, maximum compatibility

## Chafa Command Pattern
chafa --symbols [braille|block|ascii] --colors [full|256|16|none] --size WxH [image]

## Critical Rules
- ALWAYS check ChafaAvailable() before rendering
- ALWAYS validate asset.json with ValidateAsset() before using
- Asset state stored in assets/.state/[slot].txt
- Frame files MUST be listed in order in asset.json
- NEVER commit PNG frame files to git

## Asset Directory Structure
assets/[type]s/[name]/
  asset.json      — manifest
  frame1.png      — for spinners
  banner.png      — for banners
  divider.png     — for dividers
  [key].png       — for icons
