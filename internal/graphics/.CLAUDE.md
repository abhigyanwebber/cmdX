# Graphics Engine — Context for AI

## Purpose
Provides gradient, effects, divider, and pattern rendering using ANSI escape codes.

## Key Functions
- GradientText(text, fromHex, toHex) — per-character color interpolation
- RainbowText(text) — 7-color rainbow
- GlitchText(text, intensity) — random character replacement
- NeonText(text, colorHex) — bold with glow simulation
- TypewriterPrint(text, delayMs) — character by character
- Divider(style, width, colorHex) — themed horizontal line
- GradientDivider(style, width, fromHex, toHex) — gradient line
- RenderPattern(pattern, width, height, colorHex) — texture fills

## Color Utility
ParseHex(hex) RGB — converts #RRGGBB to RGB struct
AnsiColor(rgb, text) string — wraps text in 24-bit ANSI foreground
AnsiBgColor(rgb, text) string — wraps text in 24-bit ANSI background
